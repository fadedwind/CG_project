# 快速开始：将视频帧转换为烟雾模拟

## 步骤1：准备帧文件

1. 在Unity项目中创建文件夹：`Assets/StreamingAssets/Frames/`
2. 将你的视频帧图片放入该文件夹
3. 确保图片命名格式为：`frame_0000.png`, `frame_0001.png`, `frame_0002.png` ... 

> **提示**：如果使用其他命名格式，可以在Inspector中修改 `frameNameFormat`

## 步骤2：设置场景

1. 打开你的烟雾模拟场景（应该有 `SmokeComputeManager` 对象）
2. 创建一个新的GameObject（或使用现有的）
3. 添加 `VideoFrameToSmoke` 组件

## 步骤3：配置参数

在Inspector中设置以下参数：

### 基本设置
- **Smoke Manager**: 拖入场景中的 `SmokeComputeManager` 对象
- **Frames Folder Path**: `Frames` （如果放在StreamingAssets/Frames）
- **Frame Name Format**: `frame_{0:D4}.png` （默认格式）
- **Start Frame Index**: `0`
- **Total Frames**: `0` （自动检测）

### 播放设置
- **Auto Play**: ✅ 勾选
- **Playback Frame Rate**: `30` （根据你的视频调整）
- **Loop**: ✅ 勾选（如果需要循环）

### 烟雾设置
- **Brightness Threshold**: `0.5` （黑白视频推荐值）
- **Smoke Intensity Multiplier**: `1.0` （可以后续调整）

## 步骤4：运行

点击Play按钮，你应该能看到：
1. 帧序列被加载
2. 每一帧被转换为障碍物和烟雾源
3. 烟雾开始模拟和扩散

## 调整技巧

### 如果烟雾太淡
- 增加 `Smoke Intensity Multiplier`（例如：2.0 或 3.0）

### 如果烟雾太浓
- 减少 `Smoke Intensity Multiplier`（例如：0.5）

### 如果边界不对
- 调整 `Brightness Threshold`（0-1之间）
  - 值越小，更多区域变成烟雾源
  - 值越大，更多区域变成障碍物

### 如果播放速度不对
- 调整 `Playback Frame Rate` 使其与原始视频帧率一致

## 常见问题

**Q: 帧加载失败？**
- 检查文件夹路径是否正确
- 确保帧文件存在且命名格式正确
- 查看Console窗口的错误信息

**Q: 看不到烟雾？**
- 检查 `SmokeComputeManager` 的 `Smoke Display Factor` 是否大于0
- 尝试增加 `Smoke Intensity Multiplier`
- 按Tab键切换显示模式，确保在"Smoke"模式

**Q: 性能问题？**
- 减少 `SmokeComputeManager` 的 `Resolution`（例如：320x180）
- 减少帧数或降低播放帧率
